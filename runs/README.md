# runs/ layout

- **`qcdloop/`** — the consolidated qcdloop application driver plus the
  pipeline's run tooling. A single `boxGPU_tracked` main() dispatches all 21
  in-scope box integrals (B1–B16, BIN0–BIN4) through the public
  `ql::BO<TOutput,TMass,TScale>()` entry point, each wrapped in a nested
  `tracked::scope("integral=<name>")` / `tracked::scope("sample=<i>")` pair.
  One shim (`src/ql_tracked_interop.hpp`), one C8 patch
  (`src/ql_tracked.patch`), one build. Emits `journal.jsonl` (scope-tagged) +
  `journal_meta.json`. Entry points: `run_strategy_e2e.py` (strategy walk),
  `run_all_integrals.py` (per-integral fan-out), `run_chunked.py` (chunked
  characterization), `run_solver_stage{1,2}.py` (scorer-manifest solver).
  Design docs of record and the current validated reports live here too — see
  the top-level `README.md`.
- **`qcdloop_headers_full/`** — vendored upstream qcdloop headers
  (`ReetBarik/qcdloop@8de2089`), all box families B0m..B4m. The consolidated
  driver builds against this tree and it is the Validator's pristine vanilla
  baseline; the C8 patch is applied at build time and reset afterward.
- **`cancellation/`, `cln/`, `kahan/`, `lnrat/`, `log_sum_exp/`,
  `naive_variance/`** — the characterizer calibration micro-fixtures, driven
  end-to-end by `scripts/regen_recall.sh` (build → run →
  `agents.shared.regen_profile` → `agents.shared.recall_verifier`). Each
  carries its committed `journal.jsonl` + `sensitivity_profile.json`.
- **`recall_summary.json`** — the committed recall-verifier output over the
  fixtures, regenerated by `scripts/regen_recall.sh`.

Retired per-target Stage-2 scaffolding (`archive/stage2/`) was removed in the
2026-08 sanitization pass; recover it from git history if ever needed.
