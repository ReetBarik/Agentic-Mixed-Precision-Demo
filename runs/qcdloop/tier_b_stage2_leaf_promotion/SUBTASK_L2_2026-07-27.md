## 1. `clonable_leaf` predicate — clauses + refusals table

The predicate (`clonable_leaf.clonable_leaf`) is **pure and side-effect-free**: it
reads source only through injected callables (`resolve_primary_body`,
`source_instantiates_at_dd`, `is_class1_synthesizable`, `CallGraph`) and mutates
nothing.  It encodes DESIGN §1.2 clauses (1)–(4) verbatim, returning
`ClonableLeafResult{ok, reason, transitive_deps}`.

| clause | check | on failure |
|---|---|---|
| (1) | body available in the analysed source (not extern / vendored-binary) | refuse — `clause (1)` |
| (2) | body's callees resolve ONLY to: a vendored `quad::ddfun` op / a surface-provided `<cmath>` op / a source-instantiated Class-2 symbol / a Class-1 synthesizable wrapper / another `clonable_leaf` (recurse) | refuse — `clause (2)` (records the offending callee) |
| (3) | NOT self-recursive under a **same-name overload set** a rename cannot separate (`call_graph.defs[g]` count > 1 with a self-call) | refuse — `STOP #K, clause 3` |
| (4) | no inward dd widening of a **shared parameter** a non-chain caller binds (`binds_shared_param`) — a pure clone satisfies this by construction | refuse — `clause (4)/§8.2` |

**Refusals (all exercised by negative unit tests):**

| body shape | why refused | contract |
|---|---|---|
| no body / empty body | not clonable at all (clause 1) | false-neg (safe) |
| callee is a `<cmath>` op the vendored surface lacks | STOP #S — never invent a mapping | false-neg |
| callee unresolvable (no body, not vendored/Class-1/source) | can't prove it terminates at the boundary | false-neg |
| transitive inner leaf not clonable | refusal propagates up | false-neg |
| self-call under a same-name overload set | STOP #K — rename can't separate the recursion pit | false-neg |
| promotion needs inward dd on a shared-bound param | §8.2 — clones own params, so only fires on explicit evidence | false-neg |
| recursion deeper than `max_depth` (§2.8) | predicate backstop → rule (d) maps to `chain_closure_oversized` | false-neg |

**Conservative-parser contract held:** every uncertainty → `ok=False`.  A
false-negative (refuse a clonable leaf) is safe; a false-positive (clone an
un-instantiable leaf) is the STOP #K hard-fail — never emitted here, and L3's compile
test is the final pre-emission guard.

**Boundary classifier reuse.** `is_dd_boundary` (the §2.6 four-kind test — vendored
op / `<cmath>`-on-surface / source constant / Class-1 wrapper) is shared by the
predicate's clause (2) **and** rule (d)'s candidate filter, so the two never disagree
on what is a leaf vs. a boundary symbol.

## 2. Rule (d) frame-discovery — mechanism

`_discover_leaf_frames` runs **after** the a/b/c fixed point, only when a
`LeafPromotionContext` is supplied (the L2 opt-in; see §5 STOP #B).  Per DESIGN §1.1:

1. **Candidate selection.**  Every call on a chain line whose target is *not* (a) a
   chain frame (rule-(c) edge), (b) a functional cast (`TOutput(x)`), (c) an indexed
   kernel-output store (`res(i,0) = …`), or (d) a dd-boundary symbol (`is_dd_boundary`
   — a vendored op / Class-1 wrapper / source constant the pipeline synthesizes or
   reads, never clones).  Deterministic first-appearance order.
2. **Predicate test.**  Each candidate runs through `clonable_leaf`.  On `ok`, the leaf
   (and every transitive clonable dep it names) is recorded as a new frame with a
   per-integral clone name `g_<integral>` and a reroute
   `leaf_reroutes[g] = g_<integral>`; on refusal it becomes a narrowed `leaf_escapes`
   entry (a *smaller* `chain_closure_escapes` frontier, §4.2).
3. **Recording only.**  No `VariantSpec`, no body emission, no reroute application —
   L3 consumes `leaf_reroutes` / `leaf_frames` to materialise `Lnrat_B10`.  The a/b/c
   result is untouched (§5).

`scan_call_targets` scans only the function **body** (`_body_only` strips the
signature so the definition's own name is never read as a self-call) and excludes C++
call-keywords (`if`/`for`/`return`/`static_cast`/…) so control flow is not mistaken
for a callee.

## 4. §2.8 circuit breaker

`chain_closure_oversized` fires if rule (d) would grow `F` past `max_frames` (default
**8**) or a leaf recurses past `max_depth` (default **3**).  It is a `chain_promote`
terminal computed **before any tree mutation** (graceful degradation, not a scope
choice).  Verified:

* B10 with `max_frames=3` (its 3 chain frames + Lnrat = 4) → `chain_closure_oversized`
  fires, `leaf_frames == []`, `chain_promote` returns no variants / no files touched.
* B10 at the default `max_frames=8` → does **not** fire (`leaf_frames == ["Lnrat"]`).
  For Group A the breaker never fires (§2.8) — this is a backstop.
* A synthetic 4-deep leaf chain trips the predicate's `max_depth` backstop, which rule
  (d) maps to `chain_closure_oversized` (the depth-cap reason is recognised).

## 5. STOP audit

| STOP | condition | outcome |
|---|---|---|
| **#K** | predicate false-positive (clones an un-instantiable leaf) → L3 build fails | **guarded.** The predicate refuses on every uncertainty (missing body / unresolvable callee / same-name overload self-recursion / inward shared-param widen / STOP #S math gap / depth cap). L2 emits nothing, so no clone can break a build yet; L3's synthesized-shim compile test is the final pre-emission proof. Clause (3) is the direct STOP-#K guard (a same-name overload set the rename cannot separate — the exact Subtask-5 recursion pit — is refused, `test_clause3_self_call_overload_set_refuses`). |
| **#B** | accept↔reject flip; B13/B14 must stay byte-identical | **DISCHARGED.** Rule (d) is **inert without `leaf_ctx`** (every pre-L2 caller, incl. `chain_promote`'s production path): the a/b/c fixed point runs unchanged and the closure's enlarged fields are byte-identical. `test_no_leaf_ctx_is_byte_identical` pins every field (`closure_widenable`/`closure_decl_widens`/`designed_exits`/escapes/`return_widens`/`closure_body_names`) equal with vs. without the context. Whole offline suite regenerates the pre-L2 result exactly: **425 pre-existing tests pass byte-identically** (see §6). B13/B14 accept/reject verdicts are decided by the a/b/c gates, which L2 does not touch; rule (d) only *records* a leaf frame for L3. |
| **#U** | a new edge case surfaced in the real tree → STOP and report | **HANDLED (three found + fixed, all in the candidate filter, none a scope change).** The real B10 tree exposed, in order: (1) the leaf's own signature name read as a self-call → fixed by scanning `_body_only`; (2) boundary symbols (`kLog` Class-1, `_pi2o6`/`_half` source constants) wrongly promoted to frames → fixed by routing candidates through the shared `is_dd_boundary` classifier; (3) the kernel-output store `res(i,0)` and the `if(` keyword read as callees → fixed by excluding store containers + `_CALL_KEYWORDS`. Each is a scanner-precision fix (conservative, false-negative-safe), **not** a widening of the predicate's acceptance surface. After all three, B10 discovers exactly `Lnrat` — the design's prediction. No assumption in §1.2/§2.6/§2.7 failed; the Verdict gate does **not** fire. |
| **#S** | delegation to a `<cmath>` op the vendored surface can't map (inherited from L1′) | **HANDLED (refuse).** `is_dd_boundary` / clause (2) refuse a math callee absent from `surface.scalar_ops ∪ complex_ops` (`test_clause2_math_op_absent_from_surface_refuses`), never inventing a mapping. |

No STOP was left silently open.  STOP #U fired exactly as the brief anticipated
("new edge case → STOP and report") and was resolved by tightening the candidate
scanner to match the predicate's own boundary classification — not by relaxing any
acceptance clause.
