## 2. The seam — `e3d2e45` moved Class-1 from "synthesize" to "source"

L1′/L2 were designed against the **double-primary** `kokkosMaths.h`, in which `kAbs`,
`kLog`, `Real`, `Imag`, `Sign` exist **only** at `double` / `Kokkos::complex<double>`.
Under that source, the pipeline **must synthesize** the dd Class-1 overloads (that is
L1′'s whole job; `is_class1_synthesizable(ql::kAbs …) = True` in the design). The v3
memory even records this split: *"Class-1 = pipeline-synthesizable via extending the
Gap-A bridge; Class-2 dissolved by source enrichment."*

But `e3d2e45` ("add kokkosMaths_dd.h … as source input"), which the memory describes as
adding **only** the 43-coeff dd `Constants<T>` (Class-2), in fact ships a header that
**also defines every Class-1 wrapper at dd** — verbatim from the `ddfun_enabled` fork:

| symbol | enriched `kokkosMaths_dd.h` line | signature |
|---|---|---|
| `kAbs` | 296 / 314 | `ddouble kAbs(ddouble)`, `ddouble kAbs(ddcomplex)` |
| `kLog` | 302 / 319 | `ddouble kLog(ddouble)`, `ddcomplex kLog(ddcomplex)` |
| `kSqrt`| 308 / 324 | `ddouble kSqrt(ddouble)`, `ddcomplex kSqrt(ddcomplex)` |
| `kConj`| 329 | `ddcomplex kConj(ddcomplex)` |
| `Real` | 346 / 350 | `ddouble Real(ddouble)`, `ddouble Real(ddcomplex)` |
| `Imag` | 338 / 342 | `ddouble Imag(ddouble)`, `ddouble Imag(ddcomplex)` |
| `Sign` | 354 / 366 | `ddouble Sign(ddouble)`, `ddcomplex Sign(ddcomplex)` |

So under the **enriched** source, Class-1 is no longer a synthesis obligation — the
source already provides it, exactly as it now provides the 43-coeff Constants. The
pipeline synthesizing it too is now **redundant and conflicting**.

### 2.1 The concrete failure (the adapted L1′ P2 / L3(c) probe)

Compiling `Lnrat_B10` + **the pipeline's actual synthesized overlay** +
`kokkosMaths_dd.h` + vendored dd:

```
/tmp/leaf_overlay.hpp:8:33: error: ambiguating new declaration of
    'auto ql::kLog(const quad::ddfun::ddcomplex&)'
runs/qcdloop_headers_full/kokkosMaths_dd.h:319:26: note: old declaration
    'quad::ddfun::ddcomplex ql::kLog(const quad::ddfun::ddcomplex&)'
… (same for kAbs, Sign ×2)
compile rc=1
```

The synthesized `ql::kLog(ddcomplex)` (an `auto`-returning delegate to
`quad::ddfun::log`) and the enriched-source `ql::kLog(ddcomplex)` (a concrete
`ddcomplex`-returning definition) are **two definitions of the same overload** — an ODR
/ ambiguating-redeclaration collision. STOP #K at leaf-body level, exactly as the
verdict gate anticipated.

### 2.2 The seam also breaks the synthesizer *upstream* of compile

It is not only a C++ collision. Fed the enriched source, L1′'s `synthesize_for_region`
**raises before emitting**:

```
ShallowWrapperError: non-idempotent emission for
    ('ql', 'kLog', 'quad::ddfun::ddcomplex'): two distinct overloads
```

because `_find_primary_defs(kLog, …)` now returns **both** the `double` template
primary and the enriched dd overload, and the emitter's idempotence guard (correctly)
refuses to reconcile two distinct primaries for one `(ns, fn, type)` key. So the seam
manifests at **two** layers — the synthesizer's own guard and the C++ compiler — both
pointing at the same root cause.

### 2.3 Why L1′/L2 did not catch it

* **L1′** compile-tested its overlay against **synthetic** region sources
  (`_region_sources_full()` in `test_shallow_wrapper.py`) + vendored dd **only** — it
  never included `kokkosMaths_dd.h`, so the collision could not surface there. Its P2
  probe (`probe_clone_synth.cpp`) likewise `#include`s `kokkosMaths.h` (double primary)
  and **hand-writes** the WITH_SYNTH overlay with an explicit `NOTE: Constants<ddouble>
  is NOT specialised here` — it predates and is blind to `kokkosMaths_dd.h`.
* **L2** is pure frame *discovery* — it records `leaf_reroutes={Lnrat: Lnrat_B10}` and
  never emits or compiles anything, so the collision is invisible to it too. Its
  `clonable_leaf` predicate calls `is_class1_synthesizable` against the **double-primary**
  source (the `_SOURCE_DD` test fixture), where the answer is still "synthesize."
* The collision requires the **conjunction** of all three L3 inputs (clone + synthesized
  overlay + enriched source) in one TU — which first exists **at L3 emission**. That is
  precisely why the dispatch put the verdict gate here.

**Confirmation that the pre-enrichment path is healthy:** the *original* L1′ P2 probe
(double-primary `kokkosMaths.h` + hand-written WITH_SYNTH overlay, **no**
`kokkosMaths_dd.h`) still compiles + runs + matches double bit-for-bit
(`|diff| = 0.000e+00`). Nothing in L1′ regressed; the enriched source simply makes the
synthesize-Class-1 path a duplicate.

## 3. Why this is a scope call, not an L3 code fix

The fix is a **policy decision about how Class-1 is resolved under the enriched
source**, which changes the contracts of L1′ and L2, not just L3's plumbing. The
candidate resolutions (for Reet to choose — I did **not** implement any):

| # | resolution | touches | risk |
|---|---|---|---|
| **A** | Treat the enriched-source dd Class-1 wrappers as a **dd boundary** (like the 43-coeff Constants): `is_dd_boundary` / `is_class1_synthesizable` return "source-provided, do NOT synthesize" when the source already defines the symbol at the dd type. Overlay shrinks to ∅ for these; the leaf clone builds against source alone (proven §1.2). | L1′ (`shallow_wrapper.is_class1_synthesizable` / `_find_primary_defs` dd-awareness), L2 (`clonable_leaf` clause 2(ii) → the wrapper is now a *boundary*, not a *synth dep*), L3 (overlay assembly consumes the narrowed set) | **Lowest.** Mirrors the Class-2 dissolution `e3d2e45` already did; the leaf-alone compile (§1.2) is the existence proof. But it re-opens L1′'s `is_class1_synthesizable` and L2's predicate — a joint change, not L3-local. |
| **B** | Make the synthesizer **idempotent against an already-dd-defined primary**: if `_find_primary_defs` finds a concrete dd overload for `(ns, fn, type)`, skip synthesizing that shape instead of raising. | L1′ (`shallow_wrapper` emitter + `_find_primary_defs`) | Medium. Silences the guard that (correctly) protects against two-distinct-primaries; needs care not to mask a *real* conflict. |
| **C** | Emit the overlay into a **distinct namespace / with `inline`+ODR-safe reconciliation** so both definitions coexist. | L3 emitter + shim include machinery | **Highest / wrong.** Two live definitions of one op is fragile and violates the "no vendored-primitive duplication" spirit; rejected. |

**A** is the design-consistent choice (it finishes the job `e3d2e45` started — source
enrichment dissolves *both* Class-2 Constants and Class-1 wrappers), but it is a change
to **L1′'s and L2's** acceptance surfaces. Deciding it, and re-running L1′'s and L2's
test suites under it, is the joint L1′/L2/L3 review the verdict gate reserves for you.
