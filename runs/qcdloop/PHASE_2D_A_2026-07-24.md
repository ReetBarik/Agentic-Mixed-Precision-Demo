## Regression (found + fixed)

`boundary.py:445` no-local-write guard fired for **downcasts** as well as upcasts. Its
"read into an unretyped aggregate sink is truncated back → inert" reasoning holds for
upcast (ff/dd promote-to-wider, truncated at a double sink) but is false for downcast:
demoting a read to `float` in `res(i,0) /= scalefac2` genuinely loses precision that
propagates into the stored value (2c de≈5.8e-8).

The guard is also the empty-payload detector (its `promoted=False` return is the
`promotion_no_op` signal — there is no separate byte-identity backstop), so it must
still fire for a genuinely empty payload at any rung. Final condition:

```python
if not decl_writes and not caseB and (two_limb or not pure_reads):
    return region_text.split("\n"), False
```

fires when the promotion cannot land AND (the rung is an upcast OR there is nothing to
promote); only a **downcast-with-reads** falls through and promotes. Regression test
added (`test_downcast_read_only_aggregate_sink_promotes`); the 2c empty-payload test
(`test_empty_payload_flags_promotion_not_applied`, `T c = T(k)` downcast) stays green.
24 phase2d + 2c-promotion tests pass.

Expected effect on a re-run: B1 recovers `boxGPU.h:140/141/142` float DISCRIM (→ ~5-6
measured); B12 re-measures 141/142 as INERT (no new signal, and 2d-B will gate them).
